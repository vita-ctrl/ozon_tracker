# ТЗ: Трекер цен конкурентов на Ozon
## (описание продукта — что и как должно работать)

---

## 1. Что это за продукт

Приложение для продавцов на Ozon, которое следит за товарами конкурентов и сообщает, когда что-то меняется: цена упала или выросла, товар пропал со склада или снова появился.

Работает внутри Telegram — не нужно ставить отдельное приложение, всё открывается по кнопке в чате с ботом.

---

## 2. Кто пользователь

Продавец на Ozon (владелец магазина или менеджер), который хочет:
- знать, когда конкурент снижает цену, чтобы отреагировать;
- не мониторить конкурентов вручную каждый день;
- быстро понять, стоит ли ему тоже менять цену.

---

## 3. Как выглядит пользовательский путь

### 3.1 Первый запуск
1. Пользователь находит бота в Telegram, нажимает "Старт".
2. Бот присылает приветственное сообщение и кнопку "Открыть трекер".
3. По нажатию открывается приложение прямо внутри Telegram (без переходов в браузер).
4. Пользователь ничего не вводит для входа — приложение узнаёт его автоматически по Telegram-аккаунту.

### 3.2 Добавление товара на отслеживание
1. Пользователь нажимает "Добавить товар".
2. Вставляет ссылку на товар конкурента с Ozon.
3. Приложение проверяет ссылку, подтягивает название, фото и текущую цену товара — показывает превью.
4. Пользователь может дать товару свою пометку (например "Конкурент — беспроводные наушники").
5. Нажимает "Начать отслеживание" — товар появляется в общем списке.

### 3.3 Главный экран (список товаров)
- Список карточек: фото, название, текущая цена, значок наличия (в наличии / нет в наличии), изменение цены за последние сутки (стрелка вверх/вниз с процентом).
- Возможность отсортировать по цене, по последнему изменению, по дате добавления.
- Быстрый доступ к удалению товара из отслеживания (свайп или кнопка).

### 3.4 Карточка товара (детали)
- График изменения цены за последнюю неделю / месяц / три месяца.
- История: список всех зафиксированных изменений цены и наличия с датами.
- Кнопка "Открыть на Ozon" — переход к оригинальному товару.
- Настройка порога уведомлений именно для этого товара (например, сообщать только если цена изменилась больше чем на 5%).
- Кнопка "Остановить отслеживание".

### 3.5 Уведомления
Бот сам пишет пользователю в чат, когда происходит значимое событие:
- 📉 Цена конкурента снизилась — с указанием старой и новой цены, процента изменения, названия товара.
- 📈 Цена выросла.
- ❌ Товар пропал со склада (закончился).
- ✅ Товар снова в наличии.

Если несколько событий произошли одновременно (например, проверка нескольких товаров совпала по времени) — присылается одно сводное сообщение, а не несколько подряд.

### 3.6 Настройки
- Порог чувствительности уведомлений по умолчанию (в процентах) — применяется ко всем новым товарам, если не задано иное.
- Частота проверки цен (например, раз в 3 часа / раз в 6 часов / раз в сутки) — если решим дать пользователю выбор, а не зашивать одно значение.
- Возможность временно поставить все уведомления на паузу, не удаляя товары из списка.

---

## 4. Ограничения на старте (MVP)

Чтобы не переусложнять первую версию, в неё сознательно НЕ входит:
- отслеживание позиции товара в поисковой выдаче Ozon (это отдельная, более сложная функция — можно добавить позже);
- поддержка других маркетплейсов (Wildberries, Kaspi и т.п.);
- совместная работа нескольких пользователей над одним списком (например, менеджер + владелец магазина);
- экспорт данных в Excel/CSV;
- сравнение своих товаров с товарами конкурентов "один к одному" (в MVP отслеживаются только чужие товары, свои — нет).

Эти пункты — кандидаты на следующие версии после того, как заработает базовый сценарий.

---

## 5. Ограничение на количество отслеживаемых товаров

Нужно решить: будет ли лимит на количество товаров, которые может добавить один пользователь бесплатно (например, до 10 штук), с возможностью снять лимит через платную подписку в будущем. Это отдельный вопрос, который лучше зафиксировать до старта разработки, даже если монетизация не в приоритете сейчас.

---

## 6. Критерии готовности MVP

Продукт можно считать готовым к первому использованию, когда:
1. Пользователь может открыть Mini App через бота без дополнительного входа/регистрации.
2. Может добавить товар по ссылке и увидеть его в списке с актуальной ценой.
3. Приложение само, без участия пользователя, проверяет цены с заданной периодичностью.
4. При изменении цены или наличия пользователь получает сообщение от бота в течение разумного времени после проверки (не мгновенно, но и не через сутки).
5. Может посмотреть график изменения цены товара за последний месяц.
6. Может удалить товар из отслеживания.

---

## 7. Открытые вопросы к обсуждению
- Нужен ли лимит бесплатных товаров / монетизация на старте или это чисто pet-проект для портфолио?
- Как часто реально нужно проверять цены — компромисс между "актуальность данных" и "нагрузка на источник (Ozon)"?
- Стоит ли в будущем дать пользователю возможность отслеживать и свои собственные товары тоже — для сравнения "я vs конкурент" в одном интерфейсе?
